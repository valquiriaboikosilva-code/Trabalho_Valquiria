Aqui eu reuni um pouco do que estou aprendendo sobre as linguagens e ferramentas mais usadas para criar jogos. Espero que você goste e se inspire também!

Linguagens que mais aparecem nos jogos

Cada linguagem tem seu jeitinho. Umas são mais amigáveis para quem está começando, outras são bem poderosas para jogos grandes.

C#

É a linguagem principal do Unity. Muita gente começa por ela porque é organizada e tem bastante material de estudo.

C++

Uma linguagem bem poderosa. É bastante usada no Unreal Engine e em jogos que precisam de alto desempenho.

GDScript

Linguagem do Godot. Parece um pouco com Python e é bem gostosa de aprender, especialmente para quem está começando.

JavaScript

Muito usada em jogos que rodam direto no navegador. Com ela dá para criar jogos 2D bem legais usando HTML5.

Motores de jogos que eu conheci

Os motores são tipo a “casa” onde a gente constrói o jogo. Cada um tem suas vantagens.

Unity

Um dos mais populares do mundo. Tem uma comunidade gigante e serve tanto para jogos 2D quanto 3D.

Unreal Engine

Famoso pelos gráficos lindos. Muitos jogos grandes usam ele. É impressionante o que dá para fazer.

Godot

Totalmente gratuito e de código aberto. Eu gosto bastante dele porque é leve e bem acessível para iniciantes.

Construct / GameMaker

Ótimos para quem quer criar jogos 2D de forma mais visual, sem precisar escrever tanto código no começo.
